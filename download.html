Cara Install & Aktivasi

🌐 Chrome / Edge / Brave

  1. Download file .zip dari tombol di atas
  2. Extract file zip ke folder mana saja
  3. Buka chrome://extensions di address bar
  4. Aktifkan Developer mode (toggle kanan atas)
  5. Klik Load unpacked → pilih folder hasil extract
  6. Tab Google otomatis terbuka, ikuti flow aktivasi di bawah

🦊 Firefox

  1. Download file .xpi dari tombol di atas
  2. Buka about:debugging#/runtime/this-firefox
  3. Klik Load Temporary Add-on...
  4. Pilih file .xpi yang sudah didownload
  5. Tab Google otomatis terbuka, ikuti flow aktivasi di bawah

✨ Aktivasi Otomatis (super mudah!)

  1. Setelah install, tab Google otomatis terbuka dengan pencarian "mohammad ahsan al ghoni"
  2. Extension auto-click hasil pencarian pertama → buka ahsangresik.me
  3. Saat halaman terbuka, NovaShield otomatis aktif (tidak perlu klik apapun!)
  4. Badge di toolbar berubah dari ! (merah) → angka blokiran (cyan)
  5. Selesai! Iklan mulai diblokir di semua situs

💡 Alternatif: Buka popup NovaShield → klik tombol "Aktivasi Sekarang" → halaman ahsangresik.me terbuka → auto-aktivasi.
